# Anupam — Personal Developer Portfolio

Minimal responsive personal portfolio, built with one HTML file and no dependencies.

## Publish with GitHub Pages

1. Open repository Settings → Pages: https://github.com/anupammishra00011-commits/anupam/settings/pages
2. Under Build and deployment, choose Deploy from a branch.
3. Choose main and /(root), then Save.
4. After deployment, the default address should be https://anupammishra00011-commits.github.io/anupam/ .

## Optional anupam.is-a.dev subdomain

The free subdomain requires is-a.dev maintainer approval; merely having this repository does not reserve it.
Before applying, add your own truthful project descriptions and make sure the public portfolio is sufficiently complete.
Follow https://docs.is-a.dev/quickstart/ and https://docs.is-a.dev/guides/github-pages/ .
The registration file would be named domains/anupam.json, with owner.username set to anupammishra00011-commits and DNS records.CNAME set to anupammishra00011-commits.github.io (not the /anupam/ path).
Do not put email, tokens or other private data in a public registration file.
Do not attach the subdomain in GitHub Pages until the domain request is accepted and verified. Once accepted, configure Settings → Pages → Custom domain and enable HTTPS.

## Editing

Edit index.html and commit to main to update this site.
